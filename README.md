# Test Plan Analysis v2

Azure DevOps extension — modernised Test Plan Analysis Hub.

Rebuilt from scratch using:
- `azure-devops-extension-sdk` (new SDK)
- `azure-devops-extension-api` (new REST clients)
- `azure-devops-ui` (native ADO components)
- React 16 + TypeScript
- Chart.js for graphs

## Build

```
npm install
npm run build
npm run package
```
